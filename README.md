# LP Training - Generador de Informes

Aplicación web para automatizar la generación de informes mensuales a partir
de exports CSV de TrainingPeaks.

## Uso

1. Sube el archivo `workouts.csv` exportado desde TrainingPeaks.
2. Escribe el nombre del cliente.
3. Pulsa "Generar Excel".
4. Descarga el Excel y completa los campos manuales (zonas, comentarios, etc.).
5. Exporta a PDF.
